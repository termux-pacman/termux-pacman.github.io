If you have problem with package (note: the **pacman** package manager is considered a package), then create **issue** in the following repositories:
- If the package is from repo `main/x11/root` - [github.com/termux/termux-packages](https://github.com/termux/termux-packages/issues).
- If the package is from repo `tur/tur-*` - [github.com/termux-user-repository/tur](https://github.com/termux-user-repository/tur/issues).
- If the package is from repo `gpkg/cgct` - [github.com/termux-pacman/glibc-packages](https://github.com/termux-pacman/glibc-packages/issues).

If you have problems with pacman-alternatives, then create an **issue** in the [github.com/termux-pacman/pacman-alternatives](https://github.com/termux-pacman/pacman-alternatives) repo.  
<br>
If you have questions for us, you can email them to [pacman@termux.dev](mailto:pacman@termux.dev).
